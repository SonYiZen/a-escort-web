這是一個使用 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 引導的 [Next.js](https://nextjs.org) 專案。

## 開始使用

首先，運行開發伺服器：

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
用瀏覽器開啟[http://localhost:3000](http://localhost:3000)查看結果。

您可以透過修改“app/page.tsx”開始編輯頁面。當您編輯文件時，頁面會自動更新。

本專案使用 [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) 自動最佳化並載入 Vercel 的新字體系列 [Geist](https://vercel.com/font)。
